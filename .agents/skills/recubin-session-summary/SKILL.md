# Recubin Session Summary

## 手順

1. 現在の会話、作業差分、実行した検証から、事実だけを整理する。
2. `progress.md` の末尾を読み、既存記録の形式と内容を確認する。
3. 現在の日付を使い、末尾へ次の形式で新しい節を追記する。

```markdown
## YYYY-MM-DD: Codexセッション総括

- 変更内容: ...
- 判断理由: ...
- 経緯: ...
- 未解決事項: ...
- 暗黙仕様: ...
- 失敗した試行: ...
```

4. 内容は日本語で簡潔かつ具体的に書く。該当事項がなければ推測せず「なし」と書く。
5. 同じ日付の節が存在しても統合や置換をせず、独立した新しい節として追記する。
6. 既存ログの本文、順序、空白、見出しを一切書き換えない。`progress.md` が存在しない場合は作成せず、その旨を報告する。
